ELEMENTS

### ● paragraph

FULL
· element · insertable.
Fully editable — a paragraph is native contenteditable prose, every inline mark
included, insertable via slash and Enter.

The most elemental block — meaning with nothing but its own text.

[Image: paragraph — view vs edit]

✓ Editable

- Prose text — type directly in the canvas contenteditable

- Bold / italic / link — inline FormatBubble

- Inline code — code mark (block disabled, mark kept)

- Wikilink / blockref / tag / valueref — inline marks + autocomplete

- Split & merge — Enter splits, Backspace merges (free from schema)

- Insert — "/" slash menu, and the default Enter block

✗ Gaps

- — none —

Code: canvas/index.js:540-558, :557, :580-583, :807-810, :832-834;
slash-insert.js:40; bp-attrs.js:30,38

### ● heading

FULL
· element · insertable.
Fully editable in-canvas: type the text inline, change the level via Cmd-P or
Markdown — and it's slash-insertable.

A titled break, levels 1–6.

[Image: heading — view vs edit]

✓ Editable

- Text — type inline directly in the h1/h2/h3

- Level — Cmd-P "Turn into -> Heading 1/2/3"

- Level — also via "## " Markdown shorthand

- Insert — from the slash menu

✗ Gaps

- Level has no on-block control — no dropdown or bubble button, so it's editable
but undiscoverable

Fix:
Add a visible level control (dropdown or bubble button) on the heading block so
changing level is discoverable.
Code: run-convert.js:541-542, index.js:568-569 & :971-998,
command-palette.js:267-269, slash-insert.js:94

### ● list

FULL
· element · insertable.
Fully editable in-canvas: item text and bullet/ordered are both real, and it's
slash-insertable.

Ordered or bulleted list; nestable.

[Image: list — view vs edit]

✓ Editable

- Item text — type/edit inline via ProseMirror contenteditable

- Add/remove items — Enter and Backspace

- Insert — slash menu "list"

✗ Gaps

- No on-block toggle and no format-bubble button for ordered/bullet

- Ordered flip lives only in the Mod-P command palette

entry.

### ◐ byline

PARTIAL
· element · not insertable.
Barely editable: you can retype the one authors line, but the "list" is fake
middot-text — no add/remove, no marks, no insert.

An author / credit line.

✓ Editable

- Authors line — type/edit the whole line inline in the canvas

- Add an author — type a name plus a “·” separator

- Remove an author — delete their text and the “·”

✗ Gaps

- No real list — items are one “·”-joined text line, no per-author fields

- No add/remove controls — structural list ops don't exist

- Marks stripped — bold/italic/link on names silently dropped

- Not insertable — byline is excluded from the “/” slash menu

- bpId/bpType are internal attrs, not user-facing

Fix:
Add per-author fields with add/remove controls, allow link marks, and list
byline in CANVAS_SLASH_TYPES.
Code: role-nodes.js:95-99, run-convert.js:1738-1749, slash-insert.js:34-62

### ◐ composite / arrayOf / codelist / localizedText

PARTIAL
· element · not insertable.
Values of all four composite types are fully editable in the side rail — but you
can't insert one, there's no in-canvas editing, and the shape is JSON-only.

Nested schema field structures.

✓ Editable

- Composite — every subfield gets its native control

- arrayOf — text-input rows, add/remove/reorder buttons

- codelist — flat picker or stateful tree component

- localizedText — one input per configured language

- All edits — server-bound, focus-preserving, idempotent

✗ Gaps

- Not insertable — can't add any of the four from the paper

- No canvas node-view — renders opaque in the TipTap prose flow

- Field shape (subfields, element type, codelist, languages) is JSON-only

- Unknown inner field types degrade to read-only atoms

- Can't delete the whole block from the paper

Fix:
Add canvas node-views + slash-insert entries for all four, plus UI to edit field
shape instead of raw JSON.
Code: paper_field_block.ex:271-320, :399-504, :253-261;
composite_field.ex:204-328; array_field.ex:278-331;
localized_text_field.ex:110-126; slash-insert.js:32-62; paper_editor.ex:1301
