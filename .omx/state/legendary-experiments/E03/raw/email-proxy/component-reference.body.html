ELEMENTS

● paragraph

FULL · element · insertable. Fully editable — a paragraph is native contenteditable prose, every inline mark included, insertable via slash and Enter.

The most elemental block — meaning with nothing but its own text.

✓ Editable

• Prose text — type directly in the canvas contenteditable
• Bold / italic / link — inline FormatBubble
• Inline code — code mark (block disabled, mark kept)
• Wikilink / blockref / tag / valueref — inline marks + autocomplete
• Split & merge — Enter splits, Backspace merges (free from schema)
• Insert — "/" slash menu, and the default Enter block

✗ Gaps

• — none —

Code: canvas/index.js:540-558, :557, :580-583, :807-810, :832-834; slash-insert.js:40; bp-attrs.js:30,38

● heading

FULL · element · insertable. Fully editable in-canvas: type the text inline, change the level via Cmd-P or Markdown — and it's slash-insertable.

A titled break, levels 1–6.

✓ Editable

• Text — type inline directly in the h1/h2/h3
• Level — Cmd-P "Turn into -> Heading 1/2/3"
• Level — also via "## " Markdown shorthand
• Insert — from the slash menu

✗ Gaps

• Level has no on-block control — no dropdown or bubble button, so it's editable but undiscoverable

Fix: Add a visible level control (dropdown or bubble button) on the heading block so changing level is discoverable. Code: run-convert.js:541-542, index.js:568-569 & :971-998, command-palette.js:267-269, slash-insert.js:94

● list

FULL · element · insertable. Fully editable in-canvas: item text and bullet/ordered are both real, and it's slash-insertable.

Ordered or bulleted list; nestable.

✓ Editable

• Item text — type/edit inline via ProseMirror contenteditable
• Add/remove items — Enter and Backspace
• Nest sublists — Tab
• Inline marks — bold/italic/link/wikilink
• Ordered ↔ bullet — Mod-P palette "Turn into…"
• Insert — slash menu "list"

✗ Gaps

• No on-block toggle and no format-bubble button for ordered/bullet
• Ordered flip lives only in the Mod-P command palette
• Slash always inserts a bullet list — no direct ordered insert

Fix: Add a bullet/ordered toggle to the format bubble and an ordered-list slash entry. Code: command-palette.js:270-271, convert.js:406-413, slash-insert.js:42,97-103, slash-menu.js:22, format-bubble.js

◐ eyebrow

PARTIAL · element · not insertable. Fully editable text if it already exists, but you can't create an eyebrow from the canvas.

A kicker label above a title.

✓ Editable

• Eyebrow text — click in and type as plain-text prose
• Whole authored surface — the one string is fully exposed

✗ Gaps

• Not insertable — excluded from the canvas slash + command palette
• No inline marks — bold/italic/link forbidden in the text
• bpId/bpType — internal attrs, not user-authored
• Birth only via per-block form, raw JSON, or ingest

Fix: Add eyebrow to CANVAS_SLASH_TYPES; its "no node-view" exclusion reason is now stale. Code: role-nodes.js:67-90 (:70 marks, :87 hole), run-convert.js:96, slash-insert.js:35, canvas/index.js:378-379,:1534, command-palette.js:59

◐ byline

PARTIAL · element · not insertable. Barely editable: you can retype the one authors line, but the "list" is fake middot-text — no add/remove, no marks, no insert.

An author / credit line.

✓ Editable

• Authors line — type/edit the whole line inline in the canvas
• Add an author — type a name plus a “·” separator
• Remove an author — delete their text and the “·”

✗ Gaps

• No real list — items are one “·”-joined text line, no per-author fields
• No add/remove controls — structural list ops don't exist
• Marks stripped — bold/italic/link on names silently dropped
• Not insertable — byline is excluded from the “/” slash menu
• bpId/bpType are internal attrs, not user-facing

Fix: Add per-author fields with add/remove controls, allow link marks, and list byline in CANVAS_SLASH_TYPES. Code: role-nodes.js:95-99, run-convert.js:1738-1749, slash-insert.js:34-62

◐ ingress

PARTIAL · element · not insertable. Fully editable in-canvas — click into the lede and type like a paragraph, marks and all; you just can't slash-insert one.

The lede / standfirst paragraph.

✓ Editable

• Lede text — click in and type, real inline textblock
• Bold / italic / link — inline marks work in-canvas
• Body edit — round-trips to one clean {content} patch
• Not doctrine-locked — only the title is vetoed

✗ Gaps

• Not in the canvas slash menu — excluded from CANVAS_SLASH_TYPES
• Only add-path is a LiveView ghost-slot button in Studio chrome
• No in-canvas insert control for a lede

Fix: Add ingress to CANVAS_SLASH_TYPES so the slash menu can insert a lede in-canvas. Code: role-nodes.js:131,120-122; canvas/index.js:722,378-379,1534; slash-insert.js:34-62; paper_editor.ex:656,631-649; handlers/paper.ex:291-319

◐ image

PARTIAL · element · not insertable. Barely — a pre-seeded featured slot where you can only swap the picture; nothing else is typed.

A content image (src + alt).

✓ Editable

◐ field-* (native ×7)

PARTIAL · element · insertable. All 7 native field types insert and their value edits live in-canvas — but label, schema binding, and select options stay read-only config.

Schema-bound field controls.

✓ Editable

• Field value — real typed control (input/textarea/checkbox/select/date/color)
• field-select value — live <select> from the block's inline options
• Insert — all 7 types from the slash menu
• Persistence — debounced input/change coerces and patches the block

✗ Gaps

• Label — static text, only editable via per-block form or raw JSON
• fieldName (schema binding) — attr-only, no canvas UI
• Select options set — pickable but not add/remove/rename in-canvas
• field-text rows, locked/role attrs — config round-trip only

Fix: Add in-canvas controls for label, fieldName binding, and select-option editing to make the whole field authorable. Code: field-node.js:907-972 (buildControl), :527/:560 (label), :338-345 (fieldName), :571-604 (patch); slash-insert.js:55-61,161-176; paper_editor.ex:939

◐ field-image / field-reference

PARTIAL · element · not insertable. Narrowly editable — you can set the asset or linked doc in-canvas, but nothing else and you can't even insert one.

Media + reference picker fields.

✓ Editable

• Image asset — ghost frame → media picker writes value
• Reference target — typeahead pill picks a doc into value
• Both persist via patch-block {value}; undo/echo repaints the picker

✗ Gaps

• label caption — plain read-only text, no input
• refType (reference scope) — attr only, no UI
• dataset fetch-scope override — attr only, no UI
• locked/role doctrine attrs — round-tripped, no UI
• field-image has no alt/caption/title — bare asset ref
• Not insertable — excluded from slash menu, pick is a no-op

Fix: Add field-image/field-reference to CANVAS_SLASH_TYPES and expose label/refType/dataset as canvas controls. Code: field-node.js:245-281, :674-676, :711, :743-776, :797-847; run-convert.js:245-249, :2113-2116; slash-insert.js:37-62; canvas/index.js:378-379, :1534-1535

◐ composite / arrayOf / codelist / localizedText

PARTIAL · element · not insertable. Values of all four composite types are fully editable in the side rail — but you can't insert one, there's no in-canvas editing, and the shape is JSON-only.

Nested schema field structures.

✓ Editable

• Composite — every subfield gets its native control
• arrayOf — text-input rows, add/remove/reorder buttons
• codelist — flat picker or stateful tree component
• localizedText — one input per configured language
• All edits — server-bound, focus-preserving, idempotent

✗ Gaps

• Not insertable — can't add any of the four from the paper
• No canvas node-view — renders opaque in the TipTap prose flow
• Field shape (subfields, element type, codelist, languages) is JSON-only
• Unknown inner field types degrade to read-only atoms
• Can't delete the whole block from the paper

Fix: Add canvas node-views + slash-insert entries for all four, plus UI to edit field shape instead of raw JSON. Code: paper_field_block.ex:271-320, :399-504, :253-261; composite_field.ex:204-328; array_field.ex:278-331; localized_text_field.ex:110-126; slash-insert.js:32-62; paper_editor.ex:1301

WIDGETS

◐ callout

PARTIAL · widget · insertable. Only the body prose is truly canvas-editable — title is inert chrome and tone is set once at birth.

A toned box + title + body.

✓ Editable

• Body — inline ProseMirror prose, takes format marks
• Fold state — toggle via native details/summary, collapsible only
• Tone — chosen once at creation via > [!tone] shorthand
• Insert — from slash menu or > [!tone] shorthand

✗ Gaps

• Title — read-only chrome; set only via raw data-title/JSON
• Tone on existing callout — no picker; re-tone needs raw JSON
• Collapsible flag — no in-canvas toggle; JSON or compose gating only

Fix: Add an in-canvas tone picker and an editable title input to the callout node-view. Code: callout-node.js:264,272-291,301-336,345; index.js:1459,1462; slash-insert.js:31

● table

FULL · widget · insertable. Genuinely full: cells are real contenteditable inline holes and rows, cols, and header are live buttons.

A grid of cells with an optional header row.

✓ Editable

• Cell text — type directly in each cell, marks round-trip
• Rows — + row / − row buttons (− disables at 1 body row)
• Columns — + col / − col buttons (− disables at 1 col)
• Header — button flips the first row th↔td
• Insert — slash-insert seeds a headed 1-body 2-col grid

✗ Gaps

• Add/remove is trailing-edge only — no insert or delete of an interior row/col
• No drag-reorder of rows or columns
• No alignment, caption, colspan/rowspan, or column width (not in the model)
• Header is single-row only — cannot mark an interior row or a header column

Fix: Add interior insert/delete and drag-reorder for rows and columns to make blunt editing precise. Code: table-node.js:290-415 (renderHTML/buttons), TRANSFORMS:136-158, run-convert.js:1626-1633/1693-1699, slash-insert.js:53/147-155

◐ card

PARTIAL · widget · not insertable. Only title and body edit in-canvas (body silently drops formatting); media/action are raw-string inputs, tone unexposed, card not insertable.

A composed widget: title + body + media/action slots.

✓ Editable

• Title — inline contentEditable island, debounced, Enter-to-blur
• Body — the real PM contentDOM, type inline
• Media src — paste a URL into a bare text input
• Action — set label + href via two bare text inputs

✗ Gaps

• Tone (info/ok/warn/danger) — no control at all, raw-JSON-only
• Media image — read-only server-paint; no upload, picker, or alt field
• Action link — read-only server-paint; no priority or style
• Body rich text — marks flattened to plain text on render
• Card — not insertable from the slash menu

Fix: Add a tone control, media picker with alt, action-priority field, preserve body marks, and register a slash-menu insert. Code: card-node.js:159,178-196,199-219,247-260,304-371; slots.ex:280-286
