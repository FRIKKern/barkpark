Archives & resurrection

An archive is a portable bundle of an instance — database, documents, config — stored off the server. Archiving destroys the server so it stops billing; resurrecting provisions a fresh box and restores the bundle onto it, on Hetzner or Azure.

Hetzner boxes can't be paused — a stopped server still bills. Archive to stop paying, resurrect when you need it again. Resurrection typically takes 3–5 minutes.

Archives require an S3-compatible bucket configured under Settings → Storage. Until then, the Fleet page shows archive storage as unconfigured.

Health & the golden path

Every instance runs an agent that heartbeats once a minute. On top of that, the golden path is a three-step end-to-end probe that proves the instance is actually usable, not just up:

API answersThe public API responds on :443 with a valid version payload.
Login respondsThe auth flow issues a session for a probe account.
Studio rendersThe Studio UI loads and hydrates within 5 seconds.

An instance is Degraded when heartbeats arrive but a golden-path step fails, and Down when heartbeats stop for 3 minutes.
