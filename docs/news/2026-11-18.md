# Barkpark · Wednesday 18 November 2026

54 pull requests merged. Twelve went to the desk, Barkpark's own document editor, being rebuilt to match the TanStack Studio (the separate Studio app, [barkpark-studio](https://github.com/FRIKKern/barkpark-studio)). Fifteen went to bp, the command-line tool; eight of those came from setting up a self-hosted box in an Azure subscription where IT owns the network. Nine went to chat asks (a question an AI run puts to a person, such as "may I run this?"), five to the BarkUI colour sheet, four to Idempotency-Key, four to text cuts. One was Tuesday's News page.

## What a person can now do

**Create a document** ([#26970](https://github.com/FRIKKern/barkpark/pull/26970)). In a desk list, press "+": one way to start is a button, templates in the schema's desk block make it a menu. The navbar's "+" lists every way to start. The new document opens with its initial values and template filled in, and, for content types such as a post, nothing is stored until your first edit. Types born with content (task, paper, session, sheet, graph, mediaAsset) or with a layout are still made at once.

**Duplicate** ([#26975](https://github.com/FRIKKern/barkpark/pull/26975)) opens a copy with a uuid id and the same title. A slug that another document of the same type has, draft or published, shows "Slug is already in use" and blocks Publish. Only documents you can read count.

**History and Revert** ([#26966](https://github.com/FRIKKern/barkpark/pull/26966)). History opens a panel beside the form with the newest 100 revisions. Pick one: it shows read-only at its own URL. **Revert to revision**, then **Confirm**, writes it back as the draft. A document someone else deleted offers **Restore most recent revision**.

**Review changes** ([#26985](https://github.com/FRIKKern/barkpark/pull/26985)). A field that differs from the published version gets a change bar. Press it to see each changed field's diff, then **Revert** one field or **Revert all**.

**Copy and paste a document** ([#27048](https://github.com/FRIKKern/barkpark/pull/27048)). In the header's "…" menu, **Copy document** puts the whole document on the clipboard in Sanity's format. **Paste document** fills each field from the copied field of the same name where the value fits, and only fields you may change.

**Image field** ([#27053](https://github.com/FRIKKern/barkpark/pull/27053)). After an upload a preview shows, and when the schema declares an alt subfield, Alternative text is its own field. **Edit hotspot and crop** takes the mouse or the arrow keys (0.5% a press, 2.5% with Shift). The JS SDK draws Sanity's image reference shape when given the dataset ([#27123](https://github.com/FRIKKern/barkpark/pull/27123)).

**Two people in one title** ([#26988](https://github.com/FRIKKern/barkpark/pull/26988)). Two browsers typing in the same title at once keep both people's words, in the desk and the old Studio. On the desk, 10 of 10 test runs kept both, against 4 of 10 before; LiveView tests with two sessions cover both.

**Also in the desk:** a handle and an item menu on string-array rows ([#26964](https://github.com/FRIKKern/barkpark/pull/26964)); a document opened from a list or a reference takes the focus into its form ([#26997](https://github.com/FRIKKern/barkpark/pull/26997)); a top bar with a user menu (System, Dark or Light, Sign out), Help and resources, and a switcher listing only the workspaces, projects and datasets you belong to ([#26984](https://github.com/FRIKKern/barkpark/pull/26984)).

**bp for self-hosters.**
- `bp setup --target connect --token -` reads the token from stdin, `--token-file` from a file ([#27146](https://github.com/FRIKKern/barkpark/pull/27146)).
- `bp export --follow-refs` exports the chosen documents and everything they reference; with a filter, `--media` writes only the files they use, and `--schemas` every schema their types use ([#27155](https://github.com/FRIKKern/barkpark/pull/27155), [#27148](https://github.com/FRIKKern/barkpark/pull/27148)).
- `bp import` packs 5 MB batches and opens a new connection after a stalled one ([#27154](https://github.com/FRIKKern/barkpark/pull/27154)).
- `bp token create --dry-run` prints the request and sends nothing ([#27149](https://github.com/FRIKKern/barkpark/pull/27149)).
- `bp instance up` takes an existing subnet, public IP and Entra app, and waits up to 30 minutes for an Azure role to take effect ([#27153](https://github.com/FRIKKern/barkpark/pull/27153), [#27158](https://github.com/FRIKKern/barkpark/pull/27158)). `bp instance backup fetch` copies the newest backup off the VM and checks it ([#27156](https://github.com/FRIKKern/barkpark/pull/27156)).
- `--` ends the flags, so a title may start with dashes ([#27183](https://github.com/FRIKKern/barkpark/pull/27183) and two follow-ups). Paper master and ops commands reach their routes instead of a 404 ([#27184](https://github.com/FRIKKern/barkpark/pull/27184)).

**Found and fixed.**
- A weak reference (`_weak: true`) in a reference field no longer blocks deleting its target; it stays, dangling, as in Sanity. A strong one still blocks ([#27251](https://github.com/FRIKKern/barkpark/pull/27251)).
- A refusal on an owner-or-admin route names the missing workspace role, not a token permission ([#27226](https://github.com/FRIKKern/barkpark/pull/27226)).
- A full task title finds the task in search, not only a tag named by one of its words ([#27063](https://github.com/FRIKKern/barkpark/pull/27063)).
- A text cut never leaves half a flag (🇳 of 🇳🇴), in the server and bp ([#26947](https://github.com/FRIKKern/barkpark/pull/26947), [#27075](https://github.com/FRIKKern/barkpark/pull/27075)).
- Chat: an answer nothing can deliver cancels its ask instead of reading "allowed"; while the run still holds its turn, the answer is a 503 and the ask waits ([#26937](https://github.com/FRIKKern/barkpark/pull/26937), [#26949](https://github.com/FRIKKern/barkpark/pull/26949)). The other seven, one of them a test, keep asks right across a restart, a Studio reopen and a turn's end.
- The API spec offers `Idempotency-Key` (a resent write runs once) on 12 routes that already honoured it ([#27072](https://github.com/FRIKKern/barkpark/pull/27072)).

**BarkUI sheet.** The design colour source also writes a BarkUI stylesheet under UI SDK's names: a pale focus halo, five surfaces, and control edges at 3:1 or more ([#27170](https://github.com/FRIKKern/barkpark/pull/27170), [#27189](https://github.com/FRIKKern/barkpark/pull/27189), [#27194](https://github.com/FRIKKern/barkpark/pull/27194), [#27235](https://github.com/FRIKKern/barkpark/pull/27235)). Nothing reads it yet.

## Where it is slow or rough

- The image reference shape is written only where a box's flag is on or the schema asks; the SDK does not apply hotspot and crop yet ([#27053](https://github.com/FRIKKern/barkpark/pull/27053), [#27123](https://github.com/FRIKKern/barkpark/pull/27123)).
- Review changes cannot pick another range, and compares only the text of rich text ([#26985](https://github.com/FRIKKern/barkpark/pull/26985)). Old revisions of a sheet or paper are not shown in the desk ([#26966](https://github.com/FRIKKern/barkpark/pull/26966)).
- Bulk Publish does not check for taken slugs ([#26975](https://github.com/FRIKKern/barkpark/pull/26975)). The desk has no document undo ([#26988](https://github.com/FRIKKern/barkpark/pull/26988)).
- Two bp releases, cli-v1.26.27 and cli-v1.26.28, did not build while a test was red; the test was fixed the same day ([#27159](https://github.com/FRIKKern/barkpark/pull/27159), [#27163](https://github.com/FRIKKern/barkpark/pull/27163)).
