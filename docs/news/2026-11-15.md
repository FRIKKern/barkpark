# Barkpark · Sunday 15 November 2026

51 pull requests merged. Most of the day went to two places: the desk and the chat hosts. The desk is Barkpark's own document editor, being rebuilt to match the TanStack Studio (the separate Studio app, [barkpark-studio](https://github.com/FRIKKern/barkpark-studio)). The chat hosts are the computers BarkBot's bots work on.

## Desk: removing a document now tells you who points to it

Try it: open a document that other documents refer to, and press **Delete** or **Unpublish**.

- The desk's own dialog opens and asks first. It says how many documents refer to this one and lists them, each a link ([#26379](https://github.com/FRIKKern/barkpark/pull/26379), [#26381](https://github.com/FRIKKern/barkpark/pull/26381)). Unpublish now always asks.
- The document's **…** menu has **Incoming references**: every document that refers to this one, grouped by type. A row opens that document in the next pane ([#26377](https://github.com/FRIKKern/barkpark/pull/26377)).
- Each field has a **Field actions** button at its top right. **Copy field** puts the field on the clipboard; **Paste field** writes it into another field through the normal save, or says in words why it does not fit ([#26448](https://github.com/FRIKKern/barkpark/pull/26448), [#26467](https://github.com/FRIKKern/barkpark/pull/26467), one menu for the whole form in [#26479](https://github.com/FRIKKern/barkpark/pull/26479)).
- A schema's fieldsets are drawn, and one that says so folds ([#26390](https://github.com/FRIKKern/barkpark/pull/26390)). Group tabs show only while one of their fields does, and a field made read-only by a condition is locked while it holds ([#26382](https://github.com/FRIKKern/barkpark/pull/26382), [#26383](https://github.com/FRIKKern/barkpark/pull/26383)).

## Saves that went wrong without a word

- An edit made in one document could be stored into the next document you opened: its whole form, title and body included. The form now carries its document, and a save into any other is refused ([#26482](https://github.com/FRIKKern/barkpark/pull/26482)).
- One editor's save could put back another editor's older values. The desk's form buffer half of this is fixed; the old Studio can still lose the change another way, which the PR names and does not fix ([#26396](https://github.com/FRIKKern/barkpark/pull/26396)).
- A time picked in the date-time picker was dropped if another editor saved within 300 ms of it ([#26425](https://github.com/FRIKKern/barkpark/pull/26425)).
- Two people typing in one text: when one typed æ, ø or an emoji ahead of the other, the other's change was refused and had to be sent again another way. In a 10-minute test that was 7 of 328 changes. Now it lands ([#26499](https://github.com/FRIKKern/barkpark/pull/26499)).
- In the drafts view, a filtered list could show a document under a value its draft no longer has ([#26508](https://github.com/FRIKKern/barkpark/pull/26508)).

## Chat hosts: a folder for each bot

- A conversation can name a bot folder. The computer makes it inside the folder the owner approved and runs the bot there ([#26451](https://github.com/FRIKKern/barkpark/pull/26451), [#26449](https://github.com/FRIKKern/barkpark/pull/26449)). BarkBot's side merged on Monday ([FRIKKern/barkbot#62](https://github.com/FRIKKern/barkbot/pull/62)). Merged is not deployed: the host side needs the server change running first.
- A review of that work found a gap: a computer that lost the ability after a turn was queued still got the turn and could run the bot in the shared folder. Now such a turn is ended, not handed out ([#26484](https://github.com/FRIKKern/barkpark/pull/26484)).
- A workspace holds at most 10 live hosts, so one owner cannot multiply the write limit; a host whose 30-day credential ran out no longer takes a slot ([#26353](https://github.com/FRIKKern/barkpark/pull/26353), [#26408](https://github.com/FRIKKern/barkpark/pull/26408)).
- Bad enrolment data now gets a plain refusal (422) instead of a server error (500) ([#26500](https://github.com/FRIKKern/barkpark/pull/26500), [#26515](https://github.com/FRIKKern/barkpark/pull/26515), [#26516](https://github.com/FRIKKern/barkpark/pull/26516)). Five more made the host's tests hold on a busy machine ([#26430](https://github.com/FRIKKern/barkpark/pull/26430), [#26439](https://github.com/FRIKKern/barkpark/pull/26439), [#26488](https://github.com/FRIKKern/barkpark/pull/26488), [#26501](https://github.com/FRIKKern/barkpark/pull/26501), [#26512](https://github.com/FRIKKern/barkpark/pull/26512)).

## Papers, sheets, media and tasks

- **Find and replace in a paper**: Cmd+F (Ctrl+F elsewhere) opens a find bar with "3 of 17"; Cmd+Alt+F adds Replace and Replace all ([#26319](https://github.com/FRIKKern/barkpark/pull/26319)).
- **Export a paper**: an Export button downloads it as Markdown, copies it, or prints it to PDF. Walk-through with pictures: [Paper export](2026-11-15-paper-export.md) ([#26513](https://github.com/FRIKKern/barkpark/pull/26513)).
- **Charts in sheets**: select cells, press Chart, pick Line or Bar. The chart redraws when a cell changes, also from another editor ([#26446](https://github.com/FRIKKern/barkpark/pull/26446)).
- **Media library**: tick files (Shift+click for a range), then Delete, Add to folder or Remove from folder. Delete keeps files that documents still use and says how many use them. Drop files to upload ([#26376](https://github.com/FRIKKern/barkpark/pull/26376)).
- **All tasks**: a page that finds any task, closed ones included, with search, filters and sorting ([#26322](https://github.com/FRIKKern/barkpark/pull/26322)).
- **`bp doc diff`** shows what publishing would change, field by field; **`bp doc duplicate`** copies a document into a new draft ([#26437](https://github.com/FRIKKern/barkpark/pull/26437)).

## Where this fits

The desk work follows the desk editor plan step by step: references first, then fields and fieldsets, then field actions, as the PRs name them (WP1, WP2, WP7). The chat-host work is what BarkBot needed to run many bots on one computer.
