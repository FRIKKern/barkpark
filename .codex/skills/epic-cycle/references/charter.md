# Codex Epic Cycle charter

Durable decisions for Barkpark's Codex-native Epic Cycle. The wave Paper records per-wave evidence; this charter records decisions that survive waves.

## Decisions

- **D1 — Task first.** A published, claimed Barkpark task is a hard precondition for implementation.
- **D2 — Executable evidence.** Machine-checkable contracts and negative tests outrank prose assurances.
- **D3 — Live claims.** Pulse at phase boundaries and reread epochs before fenced mutations.
- **D4 — File-backed PR bodies.** Validate an exact physical Task trailer before GitHub mutation.
- **D5 — Honest orchestration.** Use narrow typed agents for independent read-heavy work when the surface can name `agent_type`; otherwise run visibly separate sequential evidence phases.
- **D6 — Isolated writes.** Concurrent builders use separate worktrees and non-overlapping file ownership.
- **D7 — Lead authority.** The leader owns decisions, Paper mutations, integration, `code_refs`, merge criteria, and completion claims.
- **D8 — Reasoning follows risk.** High effort for strategy, synthesis, decisions, Build, and review; medium for bounded Survey and Verify evidence.
- **D9 — Fleet size is proof.** A complete wave records 24 typed child assignments: 12 Survey, 6 Verify, 3 high-effort Build, and 3 Review, dispatched three at a time under the four-active-agent cap.
