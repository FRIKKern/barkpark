Barkpark Cloud style guide

The living spec for the console. Everything on this page is rendered by the shipped app.css — tokens, scales and shared components, light and dark side by side. The same file the product loads, no copies.

Sign-off surface: changes to the mark or the brand hues merge only after a human says yes to this page (charter decision 27).

The mark

A park evergreen, drawn inline in currentColor so it follows the theme with no extra assets. Shown at wordmark size (18px) and enlarged.

Color tokens

Every color the console may use. Resolved values are read live from the loaded stylesheet, per theme. The contrast pairs over these tokens are machine-checked by __css_check.mjs — a value that fails the manifest cannot merge.

Elevation, depth and motion

Four shadow steps; z-order comes from the ladder tokens (tabnav 19, topbar 20, menu 30, modal 50, toast 60) — never a bare number. Motion runs on --dur-1/2/3 with one easing; when a visitor asks for reduced motion, the durations collapse to zero and only spinners keep moving.
