Barkpark Cloud · living styleguide · P1-2

The ratified language

Canonical spec of the console remake, ported from the agency handover (ui-review-9/Styleguide.dc.html) onto the shipped app.css. Every component renders dark and light side by side from the same markup and the same tokens. The contrast pairs are not asserted here — they are machine-checked by __css_check.mjs (E5), which fails the build on any unreadable pairing. Doctrine anchors: status told once per row · provider colour is identity, never status · one primary action per screen · honest meters · failure beats false green.

Human sign-off surface (charter GR decision 27): changes to the mark or the brand hues merge only after a human says yes to this page. This file is a wholesale re-author of the old styleguide onto the new system — landing it re-runs that ratification ritual.

04 · Buttons & states

One primary action per screen; everything else is quiet. Danger confirms are type-to-confirm (the button stays gated until the name matches). Tab through a pane to see the shared focus ring.

Hover: primary lightens; ghost/danger brighten border only. Danger always ends in “…” — a confirm follows, never immediate.

06 · Triage headline & metadata line

Headline grammar: time-of-day greeting + computed triage sentence (0 issues → “All N running fine” · 1 → “One thing needs a look…” · N → count) + appended limit warnings. The metadata line carries the three status axes (health × billing × update) as quiet mono — region · size · IP · version · channel · update policy, in that order, always.

08 · Stage ladder & domain rungs

Ladder: PLAN→BUILD→STAGE→HEALTH→SWITCH→RETIRE. A failed stage skips the rest visibly (“—”) — production untouched is stated in the console, not implied. Rungs: DNS found → Points here → TLS → Serving; pending rungs get a sentence saying what happens by itself (“nothing to do”).

09 · Banners — lock, unreachable, suspended

Banner rules: amber = held/degraded (reversible, reversal named in the banner) · red = stopped/destructive · unreachable ≠ refused, and the copy must say which. Every banner names its target state and the exact exit action. The shipped .notice component carries the same grammar inline.

Production is locked to deploy #42 — both loops hold until you unlock.
Suspended since 21 July — stopped, not destroyed; back the moment payment succeeds.

10 · Empty states & skeletons

Empty state = dashed border + what it is + why you'd want one + ONE affordance. Never a bare card. Skeletons are shaped like the real rows (no spinner walls); loading text only past 3s. Reduced motion holds the skeleton static.

No webhooks configured Get notified when deploys, health changes or checks happen.

<760pxSidebar becomes a sheet behind a menu button; ⌘K becomes a search icon opening the palette full-screen (touch: no shortcut hint); action rows wrap — the ONE primary stays visible, ghosts collapse into an overflow “…” menu.
Theater/phoneStep rail stacks above the console; console max-height 40vh; the done-banner buttons go full-width. Never scale text below 13px.
GlobalHit targets ≥44px on touch; meters and pills never truncate their word (drop the sub-label first); mono strings ellipsize middle-out where the tail matters (shas, URLs keep the tail).

16 · Modal — the six families

Every dialog in the console is one of six families, all shown flat here (no overlay); in the product each sits on the scrim at --z-modal with a focus trap, and Escape / backdrop / Cancel dismissal stays available in every phase. The three confirm families share one grammar (GR41): mutate ships a live primary button with a single escaped consequence sentence; danger (no echo) carries btn-danger weight and is armed from the start — for grave-but-reversible actions (rollbacks) whose warning rides the trusted rich-body slot; destroy adds the consequence list and the type-the-name echo, its button disabled until the name matches. A failed confirm never dies into a toast: the sentence renders inline (.cm-error) and the primary morphs into exactly one recovery — Try again for transient refusals, Close for terminal ones (decision 25).
