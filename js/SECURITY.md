# Security Policy

## Reporting a Vulnerability

Please report security issues to **security@barkpark.dev**. Do NOT open a
public GitHub issue.

We aim to acknowledge within 48 hours and ship a fix within 14 days for
critical issues. Coordinated disclosure window is 90 days from acknowledgment.

## Supported Versions

| Channel  | Supported            |
|----------|----------------------|
| @latest  | yes                  |
| @next    | planned — not yet receiving releases          |
| @preview | yes (best effort — active pre-release channel) |

See `docs/decisions/` for architectural decision records.

## Bug Bounty

Not currently funded. Reporters are acknowledged in the CHANGELOG.
