# Paper Excellence — Epic Charter

Epic task: `task-4792223ca9eb5a7d` · Wave 1 Paper: `paper-excellence-wave-2026-08-12` · Wave 2 Paper: `paper-excellence-wave-2026-08-17` · Wave 3 Paper: `paper-excellence-wave-3-2026-08-17` · Wave 4 Paper: `paper-excellence-wave-4-2026-08-17`

## Vision

Close the gap between Barkpark Papers as rendered (Studio reader + editor + TUI pdrender) and the bar set by first-class Fable-authored artifacts. The finished experience: a reader opens any of the ~776 published papers and sees the artifact's breathing rhythm — narrow prose (~66–72 CPL) alternating with wide evidence (elastic to the 1040/1240px band), ruled section heads, verdict color, a framed finale — identical in Studio edit, honest in the terminal, and authorable by a cold agent through `bp paper push`. Width is allocated by component nature: prose is capped near a 66ch measure; evidence is elastic to the band. Spacing is Reader-Owned law: blank spacer paragraphs are forbidden (the publish floor reds them); readers own rhythm. The composition doctrine (Element·Widget·Section·Layout·Document) and the PortableDoc content-first doctrine govern every block decision: a new visual device is a variant on an existing rung, never a new block type, unless it holds data no existing block can carry.

**The three-surface law (wave 2, standing):** any block created or reshaped by this epic lands on ALL THREE surfaces in the same wave — the web reader renders it, BPML round-trips it losslessly (or refuses honestly), and pdrender gives an honest TUI analogue. pdrender never consumes BPML, so the law is two independent legs per block.
