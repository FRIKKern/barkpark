## Vision

Open the same task four ways — Studio, web reader, a terminal running `bp`, and the reader's
TUI toggle (the REAL Go pdrender via WASM, #1357) — and it is unmistakably one product, light
and dark. One file, `design/tokens.json`, is the only place a colour, font, or reading-scale
lives. Every surface READS a generated artifact instead of hand-duplicating it:

```
                    design/tokens.json         (hand-edit ONLY)
                           │  node design/emit.mjs --write
   ┌───────────┬───────────┼────────────┬─────────────┬──────────────┐
   ▼           ▼           ▼            ▼             ▼              ▼
 cloud       Studio       web         paper-       Go board       Go pdrender
 app.css   root.heex   globals.css  surface.css  tokens_gen.go   tokens_gen.go
 (CSS)       (CSS)      +tokens.gen.ts   (CSS)      GenLifecycle    GenTone*/GenReading*
                                                    GenBraille*     +GenPrimary/GenReadingAccent (NEW)
                                    ┌───────────────┴───────────────┐
                                    ▼                               ▼
                          internal/semrole/tokens_gen.go   api/.../render/tokens_gen.ex
                          (NEW: role→hex L/D + ansi16)      (NEW: brand/status/reading)
                                    ▼                               ▼
                             bp CLI truecolor              palettes.ex (email+article)
```

Concretely at the end: `bp task ready` paints `done` **teal** (not health-green) and
`in_progress` the **same blue** as the Studio board, via a truecolor→256→16→NO_COLOR ladder;
the TUI/pdrender chrome accent is **evergreen** (the legacy `#1d4ed8` blue era is over) —
and because the WASM reader renders real pdrender, that evergreen lands INSIDE the browser next
to evergreen chrome; a Barkpark email's button is evergreen, not the stray indigo `#4f46e5`;
the paper reads the same serif everywhere. Drift becomes a failing exit code, not a design
review: a **no-stray-literal ratchet** holds every adopted surface's hand-authored hex count at
its allowlist (shrink-only), and one **Coherence Spread** page shows all four surfaces side by
side in both themes for the human "this is one product" sign-off.

**Adopted = the hand-tuned twin is DELETED.** Today the two Go `*_gen.go` files are *additive
stubs with zero consumers* — a green gate lying about coherence. The endgame is that the
generated bytes ARE the live values, nothing sits outside them.

## Decisions

1. **tokens.json wins every hue conflict; adoption = DELETION of the hand-tuned twin, never coexistence.** — an unconsumed generated artifact is drift with a passing gate; deleting the duplicate is the only state where drift is *impossible* rather than *detected*.
2. **The emit foundation is ONE additive slice that owns `emit.mjs`/`check.mjs`/`tokens.json` for the whole epic; every consumer slice then touches only its surface file.** — makes the rest of the epic embarrassingly parallel and keeps the shared bottleneck single-owner (no two builders in `emit.mjs`).
3. **CLI/TUI colour = truecolor-first with a degradation ladder (24-bit → ANSI-256 → basic-16 floor → NO_COLOR), sourced from an emitted `internal/semrole/tokens_gen.go`, reusing `paper_cmd.go`'s existing termenv profile machinery.** — the terminal is the seam operators touch most; semrole already owns the vocabulary so it should own the hex; `paperResolveProfile`/`paperTermenvProfile`/`lipgloss.SetColorProfile` already exist — don't invent a switch.
4. **Lifecycle cells resolve the LIFECYCLE hue, so `done` paints teal (`#0d9488`/`#2dd4bf`) in `bp task` tables, not flat ok-green.** — `semrole.For` role semantics stay untouched (done is still semantically `ok`); only the paint layer gains lifecycle hues, exactly as tokens.json documents.
5. **TUI/CLI + pdrender chrome accent goes evergreen (kill `pdAccent #1d4ed8`); lifecycle `in_progress` STAYS token blue.** — chrome accent (selection/links/action buttons/L2 headings) is brand; `in_progress` blue is a lifecycle token, not chrome. The retint ships into the WASM reader for free.
6. **pdrender status tones adopt `GenTone*` as a DELIBERATE retint (`toneOK #047857` → token ok); the article terracotta is TOKENIZED (`color.reading-accent`), not deleted.** — per-surface warm character is fine IFF token-sourced; zero drift means one SOURCE, not one hue everywhere.
7. **paper-surface adoption = var-bridge, not rule rewrite: re-base `--paper-font-serif`/`--bp-h*-size` onto the emitted `--tok-reading-*` block (today: ZERO consumers).** — values already coincide so it's render-identical and byte-verifiable; low blast radius on the strictest view↔edit-parity surface; the paper-editor mirror (#1345) re-derives the editor for free.
8. **`palettes.ex` becomes an emitted-from-tokens Elixir artifact (`render/tokens_gen.ex`): email indigo `#4f46e5` → evergreen unconditionally; article terracotta → `color.reading-accent`.** — emails are a real reader surface carrying a third brand colour nobody chose; consumed at compile time so `mix run --no-start` render stays pure.
9. **Reading-serif self-hosting (Source Serif 4 variable woff2, first in `font.reading`) is BUILT but flag-gated; the cutover is human-gated.** — the wish names self-hosted fonts as endgame, but it changes every paper's macOS look (Iowan → Source Serif); flag-off byte-identical, before/after renders for sign-off, reversible via one token edit.
10. **The drift gate graduates from mirror-parity to LIVE-WIRING (§6 → §7) via a no-stray-literal ratchet with a shrink-only allowlist; this is the epic's EXIT criterion and lands LAST as its own slice.** — Part A only proves emitted bytes are current; it cannot see a hand hex sitting next to the generated block, which is exactly today's `theme.go`/`paper-surface.css`/`palettes.ex` state.
11. **The coherence bar is ONE four-up Coherence Spread page (Studio chrome · web reader · paper surface · real pdrender-WASM TUI) in light+dark, plus the machine §7 matrix — not a checklist or pixel-diff CI.** — "feels like one product" is a gestalt only judgeable with all four surfaces on one screen in both themes; machines enforce the enforceable (hex/var/glyph), the page carries the residual taste judgment.
12. **Scope fence + a deferral.** Builders do NOT touch `au-w2-studio-sweep` / `au-w3-web-sweep` (owned by agent `aesthetic-w12`). The cloud `app.css` second-`:root` re-declaration is **deferred to investigation, not a blind delete** — it is commented (app.css ~L219) as a deliberate dark-cascade fix, so whether it is a shadow bug or load-bearing needs a scoped look before any removal.

## Roadmap

Integration order. The foundation (S1) unblocks everything; wave-1 consumer slices ride
already-shipped artifacts and are independent of S1; wave-2 consumers ride S1's new symbols;
the ratchet lands last so the sweeps become a standing gate.

### Wave 1 — foundation + independent adoptions + the coherence instrument
- **S1 — Emit foundation (owns `emit.mjs`/`check.mjs`/`tokens.json` for the epic).** [large]
  Emit `internal/semrole/tokens_gen.go` (status role hex L/D + lifecycle hex + pinned ANSI-16
  fallback per role, info→blue). Extend `pdrenderGo()` with `GenPrimary/GenPrimaryFg/GenInk/
  GenDim/GenRule/GenReadingAccent`. New Elixir whole-file artifact `render/tokens_gen.ex`
  (brand=evergreen, brand_text, rule, status tones, reading-accent, reading font/scale). Add
  `color.reading-accent` (terracotta `#a23925` as HSL) to `tokens.json`. Register all in
  `ARTIFACTS` + `check.mjs` Part A. Add `semrole.Color()`/`Roles()`. **Rewires NO consumer** —
  pure additive stubs, exactly the W1 posture.
- **S2 — taskboard consumes `GenLifecycle` (delete the hand twin).** [medium] `theme.go`/
  `spinner.go`/`components.go`/`board.go` read the EXISTING `tokens_gen.go`; delete
  `okColor…cancelColor` + frame literals. Render-identical (values already 1:1).
- **S3 — pdrender adopts existing `GenTone*` + `GenReading*` (status retint).** [medium]
  `tone*` → `GenTone*`, reading consts → `GenReading*`; regen goldens (deliberate: `toneOK
  #047857` → token). Accent/terracotta stay put — they land in wave 2 on S1's new symbols.
- **S4 — paper-surface.css var-bridge.** [medium] Re-base `--paper-font-serif`/`--bp-h*-size`
  onto the emitted `--tok-reading-*` block. Render-identical; mirror re-derives the editor.
- **S5 — Coherence Spread static harness.** [medium] `cloud/priv/static/__preview__/
  coherence.html` — four surfaces, one light/dark toggle over `data-theme`, pure helpers behind
  `__bpTestHook`. The standing instrument; gets more coherent as slices land.

### Wave 2 — S1-dependent consumers
- **S6 — CLI truecolor ladder + lifecycle teal + `bp style`.** [large] `ansiForRole` (table.go)
  → resolve over `semrole.Color`, 24-bit→256→16→NO_COLOR + `BP_COLOR` escape hatch, reusing
  `paper_cmd.go` termenv machinery; lifecycle cells paint teal. New `bp style` terminal
  styleguide + golden fixtures per profile.
- **S7 — pdrender evergreen chrome accent + terracotta token.** [medium] `pdAccent`/L2 headings/
  links/action buttons → `GenPrimary`; `pdTerra`/pullquote → `GenReadingAccent`; regen goldens.
- **S8 — palettes.ex consumes `render/tokens_gen.ex`.** [medium] email `@brand #4f46e5` →
  evergreen; article accent → reading-accent. Run view-edit-parity after (render.ex downstream).
- **S9 — Reading-serif self-host prep (flag-gated).** [small/medium] Source Serif 4 variable
  woff2 first in `font.reading`; flag-off byte-identical; before/after renders for the human.

### Wave 3 — exit
- **S10 — Zero-drift ratchet (EXIT criterion).** [small/medium] `design/no-stray.mjs` scans
  adopted files for hex/hsl outside generated blocks against a shrink-only allowlist; extend
  `check.mjs` §6→§7 to status tones + chrome across Go+CSS at live consumption sites; wire into
  the aesthetics-guard CI. Must fail on a seeded stray literal, pass clean.
- **S11 — Coherence Spread final wiring + human sign-off (`au-w6-visual-audit`).** [medium] Point
  the Spread at the now-adopted surfaces; file residual deltas; record the sign-off.

### Deferred / investigate (not a wave slice yet)
- cloud `app.css` second-`:root` re-declaration: shadow bug or needed dark-cascade fix? Scoped
  investigation before any removal (Decision 12).
