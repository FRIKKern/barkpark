## What was wrong

`internal/cli/site_verb_matrix_test.go` built its parity `cases` as a **hand-listed enumeration**. 7 of the matrix's 15 shared verbs ran; `delete domain env github open preflight rollback settings` never ran through both spellings at all. And `matrixFixture` hardcoded one `"kind":"static"` site, so the container/BYO-repo fixture the criterion names did not exist.

The gap was **not theoretical**. `runSites` hardcoded `globals{}`:

```go
return dispatchSiteVerb(out, globals{}, siteSpellingFleet, args[0], args[1:])
```

`runCloudSiteDelete` gates on `g.yes || a.bools["yes"]`, so `bp --yes sites delete <site>` reached the shared handler with `yes=false` and **prompted at a TTY** where `bp --yes cloud site delete <site>` did not — a real behavioural difference between two spellings the row says are one implementation.

## What this ships

1. **The `cases` table is now a predicate over `siteVerbMatrix`.** The loop walks every shared row and every alias on it. Argument tails live in `siteVerbParityArgs` as *data*; a shared row with **no** entry fails the test **by name** instead of being silently skipped. Add a shared verb to the matrix and it is covered with no edit to the loop.
2. **A container/BYO-repo fixture** beside the static/content-bound one, and the loop runs over both.
3. **`globals` threaded through `runSites`** from the top-level dispatcher, closing the `delete` divergence. Both spellings now hand the shared handler the same value.

Coverage went **7 → 21 verb spellings** (15 shared rows + 6 aliases), and the loop now runs **168 cases** = 2 fixture kinds × 2 globals (`{}` / `{yes:true}`) × 2 output modes × 21 spellings, comparing request sequence, stdout, stderr and exit code at each.

The confirm gate is driven **live** (`hzStdinIsTTY` forced true) — under plain `go test` stdin is not a terminal, so the destroy prompt skips itself and the `--yes` divergence would have been invisible.

## Non-vacuity floors

- `>= 15` shared rows in the matrix.
- Both fixture **shapes** present, asserted by `kind` + a discriminating field — **not** by `len(matrixSiteFixtures)`. A floor that reads its expected value off the thing it guards is inert.
- Per case: a request was made **or** something was printed.
- Generated case count equals the product of the four axes.
