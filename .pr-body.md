## What this PR ships

`scripts/pds-artifact-retention.sh` — a **keep-N** retention verb *outside the
freeze*. The N most recently touched candidates survive unconditionally,
whatever their age; both name shapes are in scope; every refusal the harness
sweep makes is kept, plus two more.

It is a deletion mechanism, so it fails CLOSED. In refusal order: not a
directory · a name this apparatus does not make · another unix user's uid ·
a marker naming another HOST · a marker naming a LIVE pid here · **touched
inside the quiesce window** (default 10 min — a marker is written at `mkdir`,
the ~60 MB body lands minutes later, and a pid can be recycled between the two,
so a directory a run may still be writing is refused on mtime alone) ·
unmarked AND younger than the minimum age · inside the keep window. Dry run
unless `--apply`. A non-integer knob or a missing root REFUSES at exit 2 having
examined nothing — `[ abc -lt 3 ]` is a bash error that evaluates FALSE, which
would silently disable the clause it governs. No wildcard removal anywhere:
each `rm -rf` names one path the loop proved, one at a time.
